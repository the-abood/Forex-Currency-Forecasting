# Forex-Currency-Forecasting
End-to-end ML project forecasting daily exchange rates for 11 currencies (units per USD). Compares naive, ARIMA, SARIMA, Prophet, XGBoost, LightGBM and LSTM models per currency on a 60-day hold-out, saves the best deployable model for each, and serves forecasts in a Streamlit app packaged with Docker. Built on OANDA rates data.
